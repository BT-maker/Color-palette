# 🎨 Color Palette Generator

A modern and interactive color palette generator application. Create harmonious color palettes based on your selected base color and easily copy color codes.

## ✨ Features

- 🎯 **Interactive Color Picker**: Intuitive color selection interface
- 🌈 **Automatic Palette Generation**: Harmonious color palettes based on base color
- 📋 **One-Click Copy**: Easily copy color codes to clipboard
- 🎲 **Random Color**: Random color suggestions
- 📱 **Responsive Design**: Perfect display on all devices
- ⚡ **Fast and Smooth**: Smooth animations with Framer Motion
- 🎨 **Modern UI**: Elegant design with TailwindCSS

## 🛠️ Technologies

- **React 19** - Modern UI library
- **Vite** - Fast development environment
- **TailwindCSS 4** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Chroma.js** - Color manipulation
- **ESLint** - Code quality

## 🚀 Installation

### Requirements
- Node.js (v18 or higher)
- npm or yarn

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/color-palette-generator.git
   cd color-palette-generator
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

## 📦 Build

To build for production:

```bash
npm run build
# or
yarn build
```

Build files will be generated in the `dist/` folder.

## 🎯 Usage

1. **Select Color**: Choose your base color with the color picker
2. **View Palette**: Explore the automatically generated color palette
3. **Copy Colors**: One-click copy your favorite color codes
4. **Try Random**: Use the random button for new color suggestions

## 🎨 Color Formats

The application supports the following color formats:
- **HEX** (#FF5733)
- **RGB** (rgb(255, 87, 51))
- **HSL** (hsl(9, 100%, 60%))
